# 書庫DB自動登録スクリプト

書籍情報をスキャンまたは入力し、データベースへ自動登録するスクリプトです。

## 概要

ISBN バーコードのスキャン・手動入力・CSV 一括インポートに対応し、外部 API（国立国会図書館 / Google Books）から書誌情報を自動取得してデータベースへ登録します。
