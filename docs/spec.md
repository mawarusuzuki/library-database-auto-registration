# 仕様書 — 書庫DB自動登録スクリプト

| 項目 | 内容 |
|---|---|
| ドキュメントバージョン | 1.0.0 |
| 作成日 | 2026-04-15 |
| ステータス | ドラフト |

---

## 1. 目的

個人・小規模図書室が所有する書籍を効率よくデータベースへ登録・管理できるようにする。  
ISBN バーコードのスキャン、手動入力、CSV ファイルの一括インポートという 3 つの入力経路に対応し、外部書誌情報 API と連携することで手入力コストを最小化する。

---

## 2. スコープ

### 対象

- 書籍の新規登録・更新・削除
- 書誌情報の外部 API 自動取得
- CSV による一括インポート / エクスポート
- 登録結果レポートの出力

### 対象外（将来拡張候補）

- 貸出管理・返却管理
- Web UI / モバイルアプリ
- 蔵書の画像スキャン OCR

---

## 3. 用語定義

| 用語 | 定義 |
|---|---|
| ISBN | 国際標準図書番号（13 桁または 10 桁） |
| 書誌情報 | タイトル・著者・出版社・出版年・ページ数・ジャンルなど書籍を識別する属性情報 |
| 書庫DB | 書籍情報を格納するローカルデータベース（SQLite） |
| 外部API | 国立国会図書館サーチ API または Google Books API |

---

## 4. 機能要件

### 4.1 書籍登録

| ID | 機能 | 説明 |
|---|---|---|
| F-01 | ISBN 入力による登録 | ISBN（13 桁 / 10 桁）を入力すると外部 API から書誌情報を取得し DB へ登録する |
| F-02 | 手動入力による登録 | ISBN なし書籍のために全属性を手動入力して登録できる |
| F-03 | CSV 一括インポート | 指定フォーマットの CSV ファイルを読み込み複数書籍を一括登録する |
| F-04 | 重複チェック | ISBN が既に登録済みの場合、上書き確認プロンプトを表示する |
| F-05 | 書籍情報更新 | 登録済み書籍の属性を修正できる |
| F-06 | 書籍削除 | 登録済み書籍を論理削除（`deleted_at` を記録）する |

### 4.2 書誌情報取得

| ID | 機能 | 説明 |
|---|---|---|
| F-10 | NDL API 連携 | 国立国会図書館サーチ API（SRU）から書誌情報を取得する |
| F-11 | Google Books API 連携 | NDL で取得できない場合に Google Books API へフォールバックする |
| F-12 | オフライン動作 | 外部 API が利用できない場合でも手動入力モードで動作する |

### 4.3 検索・一覧表示

| ID | 機能 | 説明 |
|---|---|---|
| F-20 | 全件一覧 | 登録済み書籍の一覧をターミナルに表示する |
| F-21 | キーワード検索 | タイトル・著者・ISBN でキーワード検索する |
| F-22 | フィルタ | ジャンル・出版年・所在棚番号でフィルタリングする |

### 4.4 エクスポート・レポート

| ID | 機能 | 説明 |
|---|---|---|
| F-30 | CSV エクスポート | 全件または検索結果を CSV 出力する |
| F-31 | 登録ログ | 登録・更新・削除の操作ログをファイルに記録する |
| F-32 | インポート結果レポート | 一括インポート完了後に成功件数・スキップ件数・エラー件数を表示する |

---

## 5. 非機能要件

| ID | 区分 | 要件 |
|---|---|---|
| NF-01 | 性能 | 1 件の ISBN 登録を 3 秒以内に完了する（外部 API 応答待ち含む） |
| NF-02 | 性能 | CSV 1,000 件の一括インポートを 60 秒以内に完了する |
| NF-03 | 可用性 | 外部 API タイムアウト時もスクリプトがクラッシュせず継続動作する |
| NF-04 | 保守性 | 外部 API の切り替えをコード修正なし（設定ファイルのみ）で行える |
| NF-05 | ポータビリティ | Python 3.10 以上の環境で動作する（Windows / macOS / Linux） |
| NF-06 | セキュリティ | API キーは環境変数または `.env` ファイルで管理し、コードにハードコードしない |

## 6. 入力仕様

### 6.1 ISBN 入力

- 形式：13 桁数字（ハイフンあり・なし両対応）または 10 桁数字
- 例：`978-4-00-022981-9`、`9784000229819`

### 6.2 CSV インポートフォーマット

```csv
isbn,title,author,publisher,published_year,genre,shelf_location,memo
9784000229819,方法序説,ルネ・デカルト,岩波書店,1997,哲学,A-01,
9784003101803,吾輩は猫である,夏目漱石,岩波書店,2004,小説,B-02,初版
```

| カラム名 | 必須 | 説明 |
|---|---|---|
| isbn | 任意 | ISBN-13 または ISBN-10 |
| title | 必須 | 書名 |
| author | 任意 | 著者名（複数の場合は `/` 区切り） |
| publisher | 任意 | 出版社名 |
| published_year | 任意 | 出版年（4 桁整数） |
| genre | 任意 | ジャンル |
| shelf_location | 任意 | 棚番号・場所 |
| memo | 任意 | 備考 |

## 7. 出力仕様

### 7.1 ターミナル出力（一覧表示）

```
ID  ISBN              タイトル            著者          出版社    出版年  棚
--- ----------------- ------------------- ------------- -------- ------ ----
001 9784000229819     方法序説            デカルト      岩波書店  1997   A-01
002 9784003101803     吾輩は猫である      夏目漱石      岩波書店  2004   B-02
```

### 7.2 登録ログ（`logs/register.log`）

```

2026-04-15 10:23:05 [INFO]  REGISTER isbn=9784003101803 title=吾輩は猫である

2026-04-15 10:30:00 [ERROR] API_FETCH isbn=9784900000000 → Not Found
```

### 7.3 インポート結果レポート（標準出力）

```

  成功: 98 件
  スキップ（重複）: 1 件
  エラー: 1 件
詳細は logs/register.log を確認してください。
```

## 8. エラー処理

| エラー種別 | 対応 |
|---|---|
| ISBN フォーマット不正 | エラーメッセージを表示してスキップ |
| 外部 API タイムアウト | リトライ 3 回後に手動入力へ切り替え案内 |
| 外部 API 書誌情報なし | 警告表示後、手動入力モードへ移行 |
| DB 書き込みエラー | エラーログ記録後にロールバック |
| CSV フォーマット不正 | 当該行をスキップしてログ記録、残行は処理継続 |

---

## 9. 制約・前提

- データベースは SQLite を使用する（外部 DB サーバー不要）
- インターネット接続は任意（オフライン時は手動入力のみ）
- CLI（コマンドラインインターフェース）のみ提供。GUI は対象外
- Python の標準ライブラリおよび最小限の外部パッケージのみ使用する

---

## 10. 受入れ条件

| ID | 条件 |
|---|---|
| AC-01 | ISBN を入力したとき、3 秒以内に書誌情報が取得・登録される |
| AC-02 | 同じ ISBN を再登録しようとしたとき、上書き確認が表示される |
| AC-03 | CSV 100 件を一括インポートしたとき、全件正常に登録される |
| AC-04 | 外部 API がオフラインのとき、手動入力モードで登録できる |
| AC-05 | 登録・更新・削除のすべての操作がログに記録される |
